# English Workbench · 英语学习 + 个人工作台

一个前后端分离的 Web 应用，集成了英语口语学习和个人效率管理两大模块。

## 快速启动

```bash
# 1. 安装依赖（仅需一次）
pip3 install fastapi uvicorn

# 2. 启动服务
cd english-workbench/backend
python3 -m uvicorn app:app --host 0.0.0.0 --port 8000

# 3. 打开浏览器访问
# http://localhost:8000
```

或直接运行启动脚本：
```bash
bash start.sh
```

## 功能总览

### 📖 英语学习模块

| 模块 | 功能说明 |
|------|----------|
| 每日情景对话 | 6个高频场景（机场、餐厅、面试等），含关键短语讲解 |
| 词汇+句型卡片 | 15张可翻转卡片，覆盖日常+职场高频表达 |
| AI口语复述 | 3篇练习材料，附复述要点检查清单 |
| 情景角色扮演 | 6个真实场景，带入角色练习临场表达 |
| 疑难单词查询 | 输入单词获取释义+例句+用法讲解 |
| 我的单词本 | 收藏不熟悉的单词，标记掌握状态 |

### 🗂️ 个人工作台模块

| 模块 | 功能说明 |
|------|----------|
| 待办清单 | 任务管理，支持优先级、分类、截止日期 |
| 日程时间块 | 按日期规划时间块，可视化时间线 |
| 每日打卡 | 自定义打卡项目，累计统计 |
| 仪表盘 | 汇总今日任务、日程、打卡、学习记录 |

## 数据存储

所有数据保存在 `backend/workbench.db`（SQLite），无需额外数据库配置。

## 技术栈

- **后端**: FastAPI + SQLite
- **前端**: 原生 HTML/CSS/JS（无框架依赖）
- **部署**: 单命令启动，浏览器即用
